# Expense Tracker

A simple, responsive web app to track daily expenses. Add what you spent, see the total, and check which category takes most of your money.

**Live demo:** https://archana70455-hue.github.io/expense-tracker/

## Features
- Add expenses with title, amount, category and date
- Total spent and number of entries
- Spending breakdown by category
- Filter the list by category
- Delete an expense
- Data is saved in the browser (localStorage), so it stays after refresh
- Works on mobile, tablet and desktop

## Built with
HTML, CSS, JavaScript (no libraries)

## Run it
Download the folder and open `index.html` in a browser.

## What I learned
- Working with the DOM and form events
- Saving and loading data with localStorage
- Building a responsive layout with CSS Grid and Flexbox
